# Deployment

The repository is prepared for GitHub Pages.

## Canonical repository

Create a public repository named `data-center-water-audit` under the GitHub account `Kinrokin` and initialize it with a README so the default `main` branch exists.

Once the repository exists, the prepared tree can be pushed as-is. The root `index.html` is the public reading edition.

## GitHub Pages

After the files are on `main`, open **Settings → Pages** and publish from the `main` branch, root (`/`). The expected public URL is:

`https://kinrokin.github.io/data-center-water-audit/`

## Distribution order

1. Verify the live reading page and evidence links.
2. Send the newsroom pitches in `distribution/` with the public URL substituted.
3. Publish the Facebook post in `distribution/FACEBOOK_POST.txt` with the same URL.
4. Use `portfolio/RESUME_BLURB.md` on a resume/project page.

Do not describe the project as proving misconduct, proving every data center harmful, or proving net environmental benefit. The repository is an audit and decision framework.
